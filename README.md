# To-Do List CLI

Synent Technologies Python Development Internship - Task 3.

## Features

- Add tasks
- View tasks
- Mark tasks complete
- Delete tasks
- Saves tasks in a local JSON file
- Menu-driven command-line interface

## Run

```bash
python main.py
```

On this Windows machine, if `python` opens the Microsoft Store, use:

```bash
py -3.14 main.py
```

## Test

```bash
python -m unittest
```
