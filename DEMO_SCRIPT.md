# Demo Script - To-Do List CLI

## Short Introduction

Hello, my name is Dhruv Patel. This is my To-Do List CLI project for the Synent Technologies Python Development Internship.

## What To Show

1. Open the project folder.
2. Run the app:

```bash
python main.py
```

3. Add two tasks.
4. View all tasks.
5. Mark one task as complete.
6. Delete one task.
7. Mention that tasks are stored in a local JSON file.

## Closing

This project demonstrates a menu-driven CLI, JSON file storage, and basic task management operations.
